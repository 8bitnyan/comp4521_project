# Voice Command Accessibility Feature

This document provides information about the voice command feature that has been added to the HKUST School Guide app to improve accessibility.

## Overview

The voice command feature allows users to navigate and control the app using voice instructions. This is particularly helpful for users with visual impairments or mobility limitations.

## Available Commands

### Navigation Commands
- "Go to dashboard" - Navigate to the main dashboard
- "Go to events" - Navigate to the events screen
- "Go to map" - Navigate to the campus map
- "Go to settings" - Navigate to the settings screen
- "Go to facilities" - Navigate to the facilities screen
- "Go to venues" or "Go to food venues" - Navigate to the food venues screen
- "Go to accessibility" - Navigate to the accessibility settings
- "Go back" - Return to the previous screen

### Theme Commands
- "Switch to dark mode" or "Switch to night mode" - Change to dark theme
- "Switch to light mode" - Change to light theme
- "Switch to system theme" - Follow system theme settings

### Help Commands
- "Help" - Hear a list of available commands

## How to Use

1. Look for the microphone button at the bottom right corner of the screen.
2. Tap the microphone button to start listening.
3. Speak your command clearly.
4. The app will process your command and perform the requested action.
5. Tap the microphone button again to stop listening if needed.

## Settings

You can customize the voice command feature by navigating to Settings > Accessibility > Voice Commands. From there, you can:

1. Enable or disable voice commands
2. Adjust speech rate
3. Adjust speech pitch
4. Test voice command functionality

## Permissions

The app requires microphone permission to use the voice command feature. You will be prompted to grant this permission when you first use the feature.

## Troubleshooting

If voice commands are not working:

1. Check that you have granted microphone permission to the app
2. Ensure that voice commands are enabled in the accessibility settings
3. Try speaking more clearly and directly into the microphone
4. Check your internet connection, as some speech recognition features may require it
5. Make sure you're using the latest version of the app
